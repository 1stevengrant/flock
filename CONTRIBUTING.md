# Contributing to Flock

Thanks for wanting to help! Bug reports, ideas and questions are welcome as
[issues](https://github.com/flock-php/flock/issues).

## Pull requests start with an issue

Flock doesn't accept unsolicited pull requests. Before writing code:

1. **Open an issue** describing the bug or idea (or comment on an existing one).
2. **Wait for a maintainer to approve it.** An approved issue is either
   - labelled **`help wanted`**: anyone may send a pull request for it, or
   - **assigned to you**: it's yours to work on.
3. **Open a pull request** against `develop` that references the issue, e.g. `Fixes #123`.

Pull requests from outside contributors that don't reference an approved issue are closed
automatically. That's not a judgement of the work; open an issue and we'll take it from there.

If you use AI tools, you're responsible for the result: understand every line you submit and
test it yourself.
